# 分区底色渲染：实现范围与验收边界

当前模块是可执行的隔离验证路线，不是已经上线的全自动材质识别

旧路线会把候选图的空间颜色经过平滑后转移到原图，即使原图线条不动，候选图的蓝紫斑块和材质错色仍可能进入结果

新路线先确定真实的像素区域，再为每个区域绑定一个经过核验的底色，生成稀疏颜色提示交给参考图上色模型完成材质、阴影和高光渲染

重要边界：`preview.png` 只是检查分区和配色是否正确的提示预览，不是最终彩稿，也不得直接替换任务结果。它看起来像平涂或遮罩是预期限制，真正成品必须来自参考图上色模型，并另外通过源图几何和跨页配色验收

## 已实现的数据流

1. `MaterialPlan` 保存与源图等尺寸的整数标签图、保护区、区域绑定和配色版本
2. 每个非零标签恰好对应一个区域，零明确表示未知，不代表背景或皮肤
3. `MaterialSlot` 保存底色、材质、可选角色及装扮标识，多个区域或页面可以引用同一颜色槽
4. `propose_region_colour` 只输出待核验的单色建议，混色严重或内部样本不足时标记不可用，不自动接受
5. `render_material_flats` 只生成可检查的分层提示预览，候选 RGB、色相图、纹理和光照不进入该函数
6. `build_sparse_color_hint` 在每个已核验区域内部放置少量不透明色点，其余像素透明，不生成整页颜色遮罩
7. Cobra 读取同书参考图、源线稿和稀疏颜色提示，负责真正的材质、阴影和高光渲染
8. 未知或待核验部分不产生提示，报告明确不通过，不能把提示预览当作修复成品

普通材质会先去除网点颗粒，再用网点密度选择离散阴影提示，不把每个黑点直接叠回色块。只有明确标记为图案的材质才保留弱无色纹理；这仍是模型提示准备，不声称仅靠提示预览已经完成材质反射或光照推断

## 接口与存储

`save_material_plan` 创建新目录，包含 `labels.png`、`protected.png`、`plan.json`，不覆盖旧审核包，最后写入的清单是完成标记

读取时验证源图像素摘要、区域图片摘要、尺寸、标签、颜色槽及接受状态的审核记录，源图变化或遮罩被修改会拒绝读取

接受状态和审核记录只能表示有人提供了证据，不能从一个字符串推导出语义真的正确

隔离执行命令：

```powershell
paneltone material-render source.png review/plan.json experiment-output
```

输出目录必须不存在，结果为 `preview.png`、`cobra-hint.png` 与 `qa.json`。`preview.png` 是分区配色检查图，`cobra-hint.png` 是带透明通道的稀疏模型提示，两者都不是最终彩稿。通过返回退出码 0，存在未核验区域或检查失败返回 2，该命令不构造正式任务管理器，不恢复任务，不写正式数据库，不替换线上图片

共享合成入口当前仍保留隔离预览兼容参数，正式任务调用方没有自动启用。上线前必须改成由计划生成 Cobra 稀疏提示，并以 Cobra 输出作为待验收彩稿，禁止把提示预览直接发布

旧 `color-state` 中全为 `unresolved` 的几何片段不会自动转换成已接受的材质计划

## Cobra 鲜明度收尾

Cobra 的参考图上色倾向于输出柔和综合色盘。PanelTone 在样式 profile 之后执行一次有界鲜明度收尾，只增强模型已经给出可靠颜色的像素，不给白纸、灰色网点和气泡凭空染色

该收尾保持色相和明暗值不变，并限制最高饱和度，因此不会移动结构、改变光影形状或制造新的区域颜色。柔和粉彩和黑色电影 profile 在前级保留较低色度，经过收尾后仍与鲜明动画色保持可验证差异

## 分割模型的使用边界

`MaskPrompt` 和 `evaluate_mask_proposal` 检查有效坐标、正点遗漏、负点侵入、超出建议框的面积及孔洞

- 矩形框不是像素分割
- 模型的预测分割评分不是材质识别准确率
- 检查满足正负点不意味着整块物体已经圈对
- 高光遗漏不能直接全部填满，孔洞也可能是真实空隙、气泡或另一种材质
- 多个候选遮罩重叠时交集进入未知区，不采用后写覆盖前写
- 所有模型候选均保持 `proposed`，需要独立检查轮廓和绑定

## 验收

区域检查必须基于独立核验的单一底色范围，不能用整幅多色漫画的统计判断画面脏不脏

- 保护像素逐像素一致
- 与配色槽的色度偏差
- 去掉明暗变化后，同一区域内部的颜色离散程度
- 多尺度低频色度残差，用来发现平滑水斑
- 与源图约定明暗的偏差
- 未核验区域数量、范围和是否被意外改色

颜色槽不同和颜色斑驳是两个问题，测试与报告分别记录，不能因为旧图不匹配实验选取的新底色就宣称旧图存在色斑

测试包含平滑蓝紫斑块、中性孔洞、边界染色、十二像素位移、网点相关杂色、波纹污染、白色衣物、原始图案、透明源图、冲突遮罩、过期计划和独立命令执行

机器通过表示遵循给定区域和配色约束，不表示角色识别、材质识别或作者真实配色已被证明正确

## 尚未完成的上线前提

- 代表性整页的完整材质像素分区，而非只检查区域内部的小块
- 跨页人物及装扮绑定的独立核验
- 小漫画格、遮挡、图案、高光和开放轮廓的可靠处理
- 将通过复核的计划接入正常生成和事务修复调用方，以及对应的整页 QA
- 真实整页对照通过后，才允许替换正式任务结果

相关方法参考：[半引导线稿平涂研究](https://gmic.eu/publications/vmv18.pdf)、[SAM 2 官方说明](https://github.com/facebookresearch/sam2)，两者都不能提供任意漫画材质识别的全自动保证
