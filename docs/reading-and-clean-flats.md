# 阅读加速与干净底色

## 看漫画

默认显示上色结果和「流畅读图」。需要检查源图时切换「原图」或「对比」，需要放大检查时选择「高清细节」。下载仍使用原始分辨率的成品，不使用阅读缩略图。

- 单页翻阅：按钮、页码跳转、移动端滑动；放大后拖动用于平移。
- 垂直连读：鼠标滚轮或手指上下滚动；页码随视野更新，也可以输入页码跳转。切换阅读方式保留当前页。
- 清晰图未加载时显示当前页缩略图；失败显示原因及重试按钮，不留下上一页冒充新页。

后端为每个原图/结果生成两级 WebP：阅读图长边最多 1280px、300KiB；占位图长边最多 480px、48KiB。难以压缩的图像会适当减小尺寸；高清细节仍使用既有 1600px 显示图。原图、生成候选和下载包不因缓存而修改。

缓存默认在 data root 下的 `.reading-cache`，可通过 `PANELTONE_READING_CACHE_ROOT` 指定同样私有的本地目录。文件按源路径、修改时间、大小和编码版本寻址。已有缓存直接发送，缺失时进入单线程有界队列，HTTP 返回 202 和重试提示，不同步编码。前端最多两路并发请求，保留最多八张解码后的阅读图，并预取邻页。连续模式只挂载三个页面，避免整本图片同时加载。

## 为什么要分开底色与明暗

专业漫画上色常先铺底色，再单独处理阴影、光照和气氛，而不是把所有局部颜色变化直接当作正确成品。参考：[Clip Studio 底色教程](https://tips.clip-studio.com/en-us/articles/912)、[漫画分层上色流程](https://tips.clip-studio.com/en-us/articles/4660)、[Krita 线稿上色蒙版](https://docs.krita.org/en/reference_manual/tools/colorize_mask.html)。

PanelTone 的原作上色仍由源图提供几何、线稿、文字、气泡和明暗，模型只提供颜色候选。本轮加入两点：

1. 提取颜色时使用恒定的工作亮度，最后只叠加一次原图明暗，避免网点、阴影经过颜色空间截断后变成饱和度水渍。
2. 用源图边缘划分区域，只在主色明确的区域内整理色相和饱和度。白色、多色花纹或没有足够证据的区域不强制改成一种颜色。

这是一层保守的底色整理，不是新的角色识别模型，也不能保证所有物体颜色在语义上百分之百正确。文字、Logo、空白页直通规则和显式全图重绘模式均保持原边界。现有结果只通过按任务暂存、QA 和原子切换更新，旧结果保留为回滚备份。
